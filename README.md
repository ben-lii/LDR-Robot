# Teleop robot

Browser-driven Raspberry Pi robot: live WebRTC video and WASD motor control.

Local development and deploy steps will be filled in as the app is built. See `docs/` for architecture, protocol, hardware, and Pi setup.

## Workspaces

- `web/` — Next.js console (Vercel)
- `robot/` — Node server on the Pi
- `packages/protocol` — shared contracts
